# Web Research Skill

Use this skill when the user needs current market facts, competitor context, investor context, pricing, regulation, recent news, or other information that may change over time.

Behavior:
- If web search snippets are provided in the prompt, use them as supporting context and mention uncertainty when the snippets are thin.
- If no web snippets are provided and the answer depends on current facts, say what should be verified and ask for permission or source material before making strong claims.
- Never invent market numbers, funding rounds, laws, or competitor claims.
- Prefer primary sources, official docs, reputable publications, and company pages.
- Keep research findings directly tied to the pitch: market proof, objections, differentiation, risks, and sharper wording.

Output style:
- Integrate research into the coaching answer instead of dumping raw search results.
- Use concise citations only when source names or URLs are available in the provided context.
